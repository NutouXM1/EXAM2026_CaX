# EXAM2026_CaX

## Mô tả
Trang web quản lý sản phẩm đơn giản bằng HTML và Bootstrap, cho phép nhập liệu thông tin sản phẩm và hiển thị danh sách sản phẩm.

## Tính năng
- Form nhập tên, danh mục, giá và trạng thái sản phẩm.
- Bảng hiển thị danh sách sản phẩm mẫu.

## Cách chạy
1. Mở `HTML/index.html` trong trình duyệt.
2. Hoặc chạy qua máy chủ tĩnh nếu cần.

## Cấu trúc thư mục
- `HTML/index.html`: trang chính.
- `HTML/css/`: các tệp CSS.
- `HTML/js/`: các tệp JavaScript.
